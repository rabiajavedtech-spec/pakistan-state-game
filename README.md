#  Pakistan State Game

A geography guessing game built with **Python, Turtle, Tkinter, and Pandas**.  
Guess Pakistani cities and places and watch them appear on their locations on the map.

## 🎮 Features

-  Custom Pakistan map
-  60 Pakistani cities & places
-  Interactive guessing
-  Live score tracking
-  Automatic location placement
-  Custom Tkinter input window
-  Enter to submit answers
-  Escape to cancel
-  CSV-based location data
-  Pandas data handling
-  Case-insensitive answers
-  Tracks correctly guessed locations

## 🛠️ Tech Stack

- Python
- Turtle
- Tkinter
- Pandas
- CSV

## 🧠 What I Learned

- Working with CSV files using Pandas
- Filtering and retrieving DataFrame data
- Working with Turtle coordinates
- Creating custom Tkinter windows
- Handling user input
- Connecting multiple Python libraries
